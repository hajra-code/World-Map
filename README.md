# World Map Explorer

An HTML-only interactive map website developed for Web Technologies coursework.

## Pages

- **World Map:** Displays the world map and provides a clickable region for Asia.
- **Asia Map:** Displays the Asian continent and provides a clickable region for Pakistan.
- **Pakistan:** Displays Pakistan's map and a national anthem video with audio.

## Technologies Used

- HTML
- HTML image maps (`map` and `area`)
- HTML video (`video` and `source`)

## Features

- Interactive world map
- Clickable Asia region
- Clickable Pakistan region
- National anthem video with audio
- Navigation between pages
